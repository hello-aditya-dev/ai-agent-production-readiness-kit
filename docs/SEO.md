# SEO Architecture

## Production URL

`https://ai-agent-production-readiness-kit.vercel.app/`

Canonical homepage. To migrate to a custom domain, change **only** `SITE_URL`
in `src/lib/product-links.ts`. Everything else (canonical, sitemap, robots,
OG, JSON-LD, metadataBase) derives from it via `src/lib/site-config.ts`.

## Canonical rules

- Absolute canonical: `https://ai-agent-production-readiness-kit.vercel.app/`
- Generated by `alternates.canonical: "/"` + `metadataBase` in
  `src/app/layout.tsx`.
- No localhost, no preview domains, no hash URLs (`#how-it-works`), no
  duplicate paths.
- `metadataBase` is set to the production origin so all relative OG/Twitter
  image URLs resolve to absolute.

No keyword stuffing. Topics are defined in `src/lib/site-config.ts` (`SITE.supportingTopics`) and surfaced only in metadata `keywords` (a minor signal) and naturally in on-page copy.

## Sitemap

- URL: `https://ai-agent-production-readiness-kit.vercel.app/sitemap.xml`
- Implementation: `src/app/sitemap.ts` (Next.js metadata route).
- Includes the canonical homepage with `lastModified`, `changeFrequency: weekly`, `priority: 1`.
- Returns HTTP 200, valid XML.

## Robots

- URL: `https://ai-agent-production-readiness-kit.vercel.app/robots.txt`
- Implementation: `src/app/robots.ts` (Next.js metadata route). The static `public/robots.txt` was removed to avoid a duplicate implementation.
- Content: `User-agent: * / Allow: /` + `Sitemap: .../sitemap.xml` + `Host: ...`.
- Returns HTTP 200.

## Structured data (JSON-LD)

Injected in `src/app/layout.tsx` via a `<script type="application/ld+json">`. Schema.org `@graph`:

1. **WebSite** — site name, description, URL.
2. **WebPage** — page name, isPartOf, about, inLanguage.
3. **Product** — "AI Agent Production Readiness Kit" with two `Offer`s:
   - **Agency Edition** — $299.00 USD, InStock, links to Gumroad (or `#editions` fallback).
   - **Standard Edition** — $149.00 USD, InStock, links to Gumroad (or `#editions` fallback).

No fake reviews, ratings, rating counts, SKUs, or brand claims. Offer URLs point to the Gumroad checkout when configured, else to the on-page `#editions` anchor.

## Indexing status

The site is **technically indexable**:
- homepage returns 200
- robots allows crawling
- robots references the sitemap
- sitemap returns 200 and contains the canonical page
- page includes `<meta name="robots" content="index, follow">`
- canonical is absolute and correct
- no `noindex`, no `X-Robots-Tag: noindex`, no middleware blocking bots, no auth

**Actually being indexed by a search engine** is controlled by the search engine, not by this site. Making the site indexable is the prerequisite; it does not guarantee indexing or ranking.

## Custom-domain migration

Change **only** `SITE_URL` in `src/lib/product-links.ts`:

```ts
export const SITE_URL = "https://your-custom-domain.com";
```

Commit and push. Canonical, sitemap, robots, OG, Twitter, JSON-LD, and manifest all derive from this value via `src/lib/site-config.ts` (`absoluteUrl()`, `SITE_ORIGIN`). Update the Search Console / Bing properties to the new domain and resubmit the sitemap.
